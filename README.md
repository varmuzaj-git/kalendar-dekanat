# Kalendář akcí – děkanát Valašské Meziříčí

Souhrnný kalendář akcí farností děkanátu Valašské Meziříčí a Centra pro rodinu (koncerty, poutě, přednášky, kurzy Alfa, příprava snoubenců, zpovídání…).

- Web: vkládá se na https://dekanatvalmez.cz/
- `wp-plugin/kalendar-dekanat` – WordPress plugin pro ruční přidávání akcí (REST `/wp-json/kalendar-dekanat/v1/akce`) a shortcode `[kalendar_akci]`.
